# Research documentation shelf

**Inputs:** the user-approved research aim, current repository files, and named papers. **Process:** keep the single authoritative scope, baseline audit, research gates, literature map, and agent workflow here. **Outputs:** reviewed Markdown documents and paper notes made from `_templates/paper-note.md`. **Human check:** accept target definitions, data-readiness verdicts, and interpretation of prior work before an experiment depends on them.

Do not copy raw PDFs or captured datasets into this folder. Link to their existing homes. Treat `LITERATURE_MAP.md` as navigation and individual paper notes as the evidence home for detailed claims.
