# Project phases

**Inputs:** [project execution plan](../PROJECT_EXECUTION_PLAN.md), [research scope](../PROJECT_SCOPE.md), [research gates](../RESEARCH_PLAN.md), and the source documents named by each phase.

**Process:** work through numbered phase folders in order. Read a phase `CONTEXT.md`, then each task's `CONTEXT.md` and `TODO.md` index. Follow the three linked files in that task's `todos/` folder. Record evidence and outputs at the paths named by the task. Complete a gate only after the stated human check.

**Outputs:** reviewed paper notes, protocol, capture and fault manifests, evaluation reports, and final synthesis at their canonical locations. These folders contain plans, not datasets or experiment runs.

**Human check:** verify each phase gate against the source evidence before the next phase depends on it. A folder or checked box alone does not establish scientific validity.

The eight phase folders and 24 tasks are linked from [PROJECT_EXECUTION_PLAN.md](../PROJECT_EXECUTION_PLAN.md); the tasks contain 72 individual to-dos. Do not duplicate final facts here; update the scope, literature map, audit, protocol, or run report that owns them.

For execution status, follow the phase contracts. [Phase 01](01-bibliography/CONTEXT.md) and [Phase 02](02-literature/CONTEXT.md) record performed work and pending human review; [Phase 03](03-protocol/CONTEXT.md) has a protocol draft with eight performed actions and its event action awaiting signal verification; [Phase 04](04-telemetry/CONTEXT.md) has implemented collector/quality tooling and nine performed actions, with measurement readiness failed and human review pending; phases 05–08 remain plans.
