## Confirmed code defects and implemented repairs

Source inspection confirms the old extractor discarded query failures/empty matches into zero, backward-filled observations, and used exact joins against a locally generated naive timestamp index. These paths can conceal absence and use future data. The former HTTP query also used `or vector(0)`, masking missing matches. Attribution of the old all-zero capture to a particular path remains unverified because its raw responses were not retained.

[Collector implementation](../../google_boutique/telemetry_capture.py) now keeps a single aligned UTC grid, explicit aggregate cardinality, millisecond alignment tolerance diagnostics, NaN on absence/error/nonfinite values, value-observation masks, source timestamps and extraction receipt times. It does not impute. CPU/memory exclude unnamed/POD containers; network selects eth0 in cAdvisor rather than summing arbitrary interfaces. Source label sets are retained for aggregation review. Empty HTTP-error series remain missing; absence of error-code series alone cannot prove zero HTTP errors.

The [entry point](../../google_boutique/extract_telemetry.py) requires explicit bounds, provenance and a fresh output directory. A manifest starts as in-progress and is replaced by an artifact-hashed final record. Runtime Parquet availability is checked before starting; source snapshots and dependency versions are saved. The existing project `venv` supports Parquet; system Python 3.14 did not. Explicit-column tensor construction defaults to four primary features, preserves NaN, validates UTC continuity and does not generate model windows automatically during capture. Compatibility change: `output_filename` names a new directory and naive timestamps are rejected.

The quality implementation reports actual coverage, freshness, variation, values, failures, UTC alignment, workload overlap and CSV/Parquet/mask/hash parity. A pandas datetime storage-unit issue discovered during the first quality report was corrected with unit-independent timestamp conversion; its superseded report is preserved. A Redis hyphen escape caused errors in an intermediate attempt and was corrected before the canonical capture; its raw errors remain preserved.
