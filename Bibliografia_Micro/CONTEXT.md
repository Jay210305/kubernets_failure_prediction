# Bibliography source corpus

**Inputs:** PDF papers and reports already in this folder. **Process:** preserve source files and record any new source's provenance, edition, and citation details in a paper note. **Outputs:** evidence notes under `../docs/papers/` and a brief route in `../docs/LITERATURE_MAP.md`. **Human check:** confirm that a cited claim matches the original page and that duplicate filenames have not been mistaken for independent studies.

This folder had 81 PDFs and 75 distinct file hashes at the initial 2026-10-06 audit. The PDFs are currently local, untracked repository files; the map is useful only where those source files are available.
